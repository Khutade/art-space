# Art Space - Online Art Gallery 🎨

Art Space is a lightweight, frontend-only Single Page Application (SPA) designed to showcase and sell fine art. It features dynamic routing, a shopping cart, category filtering, and AI-powered artist biographies and artwork analysis using the Gemini API.

## ✨ Features
* **Single Page Application:** Fast, seamless navigation between Home, Gallery, Details, and Cart without page reloads.
* **Responsive Design:** Fully fluid and responsive layout built with custom CSS.
* **Shopping Cart System:** Add, remove, and update quantities with automatic subtotal calculations.
* **Dynamic Filtering:** Filter the gallery by specific artists or categories (Abstract, Landscape, Portrait).
* **AI Integrations (Gemini):** * Generate contextual artist biographies on the fly.
    * Generate stylistic artwork analysis for individual pieces.
* **Smooth Animations:** Staggered load-ins, hover states, and seamless page transitions.
